# The Ethics Record (working title; repo: corruption-ticker)

A living, open, evidence-graded record of sourced allegations, findings, and oversight changes in the second Trump administration, from 2025-01-20. It is a record of what has been reported and with what evidence, not a claim to be complete and not a finding of guilt. Methodology: `docs/schema.md` (evidence grades, counting rules) and `plans/concept.md`.

- `data/` — the dataset (JSON), raw research fragments, and source registry
- `docs/` — schema, inclusion rubric, editorial rules
- `plans/` — build plans and dev strategy
